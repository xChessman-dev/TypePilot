# Изменения

## 0.4.0-dev

- Исправлен прыжок курсора после заглавной буквы: диапазон вставки заканчивается у исходного курсора, без отложенного перемещения через UI Automation.
- Фоновые лёгкие правки ждут паузы от 500 мс; проверяется также время последнего ввода Windows. Набор и перемещение курсора отменяют устаревший контекстный запрос.
- Частые опечатки и случайная раскладка проверяются во всей недавней фразе, с русским и английским системными словарями. Настоящий английский не переводится автоматически.
- Регистр имён и компаний по редактируемому каноническому списку; отдельно от словаря слов, которые запрещено исправлять.
- Опциональный локальный контекстный автокорректор после паузы от 1,5 с: запятые, регистр, разделение слитных слов. Только текущий абзац до 600 символов, без перевода и перефразирования. Проверка неизменности последовательности букв и цифр отбрасывает небезопасные ответы.
- Общий ИИ-движок с переформулировкой по горячей клавише; отдельный переключатель и явное предупреждение о расходе GPU/памяти. По умолчанию контекстный ИИ выключен.
- Добавлены проверки положения курсора после правки первой буквы, продолжения ввода, редактирования середины текста и сохранности слов при автоматической ИИ-правке.

## 0.3.0-dev

- Исправлено: похожие слова больше не предлагаются для корректных слов из системного словаря. Добавлены «думать» и «мяу» во встроенный список; короткий сленг не получает случайных замен.
- В подсказке есть явная кнопка «Оставить исходное слово» и номера вариантов.
- Tab последовательно выбирает 1 / 2 / 3, вставка после паузы 600 мс; Escape и продолжение ввода отменяют выбор. Перехват существует только при видимой подсказке и отключается в настройках.
- Заглавная буква в начале предложения, аккуратные пробелы вокруг знаков, точка по двойному пробелу. Отдельные выключатели и безопасная отмена.
- Фокусирование существующего текста не запускает его автоисправление. Пунктуация по смыслу остаётся отдельным ИИ-режимом.
- Регрессионные проверки словаря, защищённых токенов, комбинированных правок, отмены и выбора Tab.

## 0.2.0-dev

- Фоновый Т9: подсказки рядом с доступным полем ввода, без перехвата фокуса; мышь или Ctrl+Alt+1/2/3 принимает слово.
- Проверяемые текстовые поля UI Automation в дополнение к Win32 Edit/RichEdit. Tab исходного приложения не блокируется.
- Ctrl+Alt+Space запускает ИИ по выделению в компактном окне. Подтверждённый результат возвращается в исходное поле.
- Повторная проверка поля, текста и выделения перед заменой; изменённый исходник не перезаписывается.
- Литеральный ввод не использует буфер обмена и не нажимает Enter. Сообщения не отправляются автоматически.
- Главная панель в стиле других настольных приложений: сетка, боковая навигация, собственная верхняя строка, тонкий скролл.
- Новая иконка клавиатуры-диалога для exe, окон и трея.
- Проверки UI Automation на синтетических полях: вставка, отмена, курсор, фокус, пароли, read-only и устаревший ИИ-ответ.

## 0.1.0-dev

- Первое ядро Т9: частые опечатки, раскладка, предложения по расстоянию Дамерау — Левенштейна и завершение слов.
- Системные словари Windows для русского и английского; отсутствие словаря не блокирует набор.
- Редактор с предпросмотром, принятием подсказок и отменой последнего исправления.
- Личный словарь, импорт и экспорт TXT; неизвестные слова не исправляются автоматически.
- Локальный ИИ Qwen3 4B: яснее, короче, вежливее или только ошибки.
- Защита значимых деталей результата: числа, время, относительные даты и ссылки. Один повтор при потере деталей, затем отказ.
- Ограниченная интеграция Edit / RichEdit через события доступности, без клавиатурного перехвата.
- Явное получение выделенного текста по Ctrl+Alt+Space, только из проверяемого разрешённого поля.
- Тёмная тема, единая сетка, собственная иконка, тонкий скролл и работа в трее.
- Модель на F, запуск по запросу, выгрузка при простое и завершение дочернего процесса при выходе.
