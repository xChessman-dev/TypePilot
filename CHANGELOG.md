# Изменения

## 0.1.0-dev

- Первое ядро Т9: частые опечатки, раскладка, предложения по расстоянию Дамерау — Левенштейна и завершение слов.
- Системные словари Windows для русского и английского; отсутствие словаря не блокирует набор.
- Редактор с предпросмотром, принятием подсказок и отменой последнего исправления.
- Личный словарь, импорт и экспорт TXT; неизвестные слова не исправляются автоматически.
- Локальный ИИ Qwen3 4B: яснее, короче, вежливее или только ошибки.
- Защита значимых деталей результата: числа, время, относительные даты и ссылки. Один повтор при потере деталей, затем отказ.
- Ограниченная интеграция Edit / RichEdit через события доступности, без клавиатурного перехвата.
- Явное получение выделенного текста по Ctrl+Alt+Space, только из проверяемого разрешённого поля.
- Тёмная тема, единая сетка, собственная иконка, тонкий скролл и работа в трее.
- Модель на F, запуск по запросу, выгрузка при простое и завершение дочернего процесса при выходе.
